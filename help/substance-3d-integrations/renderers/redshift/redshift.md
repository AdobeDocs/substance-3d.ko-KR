# Redshift

버전 2.5.43의 Redshift 재질은 금속성 워크플로우를 지원합니다. Redshift를 사용한 렌더링의 경우 Substance Painter 또는 [Maya](https://www.substance3d.com/ecosystem-plug-ins/substance-in-maya/)의 Substance 플러그인에서 내보낸 맵을 사용할 수 있습니다.

Substance Painter 2020.1(6.1.0)에는 Redshift([rsMaterial](https://docs.redshift3d.com/display/RSDOCS/Material)) [출력 템플릿](https://docs.substance3d.com/display/SPDOC/Export)뿐만 아니라 Redshift 3용 레거시 출력도 함께 제공됩니다.
