# Modo 설치

플러그인을 설치하려면 LPK 파일을 MODO로 드래그하면 됩니다. 키트 또는 MODO 콘텐츠 팩을 설치하지 않은 경우 적절한 폴더를 만들라는 대화 상자가 표시될 수 있습니다. 키트가 설치되면 MODO UI의 오른쪽 상단에 Substance 버튼이 표시됩니다.
