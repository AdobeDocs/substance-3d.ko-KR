# Substance 플러그인 사용

Substance 플러그인은 Cinema 4D 플러그인 메뉴에 있습니다.

![](../../../assets/cinema-4d-1.png){width="500px"}

## 에셋 로드...

이를 사용하여 Substance 에셋을 장면에 로드합니다. Substance 아카이브(.sbsar)만 로드할 수 있습니다. Substance Asset Manager가 아직 표시되지 않은 경우 Substance을 성공적으로 가져올 때 자동으로 열립니다. 이 명령은 Substance Asset Manager에서도 찾을 수 있습니다.

가져올 때 Substance을 프로젝트 폴더에 복사해야 하는지 묻는 메시지가 표시될 수 있습니다.

![](../../../assets/cinema-4d-2.png){width="500px"}

* &#39;아니요&#39;로 대답하면 Substance의 절대 경로가 장면에 저장됩니다.
* &#39;예&#39;로 대답하면 Substance이 프로젝트의 tex 하위 폴더에 복사되고 장면에서 파일 이름으로만 참조됩니다.

이 프롬프트는 가져올 때마다 한 번만 나타납니다(예: 탐색기 또는 Finder에서 여러 Substance을 드래그하여 놓을 때).
