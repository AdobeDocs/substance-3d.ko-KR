# 설정

## 요구 사항

Cinema 4D R16 이상이 필요합니다. Cinema 4D Lite를 제외한 모든 제품 버전이 지원됩니다.

Substance 파일은 [Substance Designer](https://www.allegorithmic.com/products/substance-designer)를 사용하여 만들 수 있습니다.

## 설치

## Windows

1. Cinema 4D은 설치하는 동안 실행하면 안 됩니다.
1. 자체 설치 패키지를 실행합니다.
1. 대상 폴더 선택/확인 이는 플러그인 하위 폴더가 아니라 Cinema4D가 설치된 폴더여야 합니다.
1. &quot;설치&quot;를 클릭합니다.
1. 설치가 완료되면 Cinema 4D 시작 옵션이 제공됩니다.

## Mac

1. Cinema 4D은 설치하는 동안 실행하면 안 됩니다.
1. cld 파일을 Cinema 4D 플러그인 폴더에 놓습니다.
1. 평소와 같이 Cinema 4D을 시작합니다.
