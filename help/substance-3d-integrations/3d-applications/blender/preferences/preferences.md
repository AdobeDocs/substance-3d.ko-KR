# 환경 설정

추가 기능 환경 설정은 Blender의 환경 설정 창에서 찾을 수 있습니다. 편집 > 환경 설정 > 추가 기능으로 이동하고 노드: 믹서기용 Substance 3D 추가 기능을 Adobe 합니다.

<b>제거</b> - 시스템에서 추가 기능을 삭제하고 Blender의 추가 기능 목록에서 제거합니다.

<b>버그 보고</b> - Blender Discord용 Substance 3D을 엽니다.

<b>도구 폴더 수락</b> - Blender 파일 브라우저를 열고 Substance 통합 도구 설치 경로를 선택합니다.

<b>도구 열기 </b>- 통합 도구 폴더 위치에서 시스템 파일 브라우저를 엽니다.

<b>경로 재설정</b> - 통합 도구 폴더 경로를 기본 위치로 재설정합니다.

<b>제거 도구</b> - 설치된 버전의 Substance 3D 통합 도구를 제거합니다.

<b>도구 업데이트</b> - 파일 브라우저를 열어 도구 zip 파일을 선택하고 도구를 업데이트합니다.

<b>설명서</b> - 브라우저에서 에코시스템 및 플러그인 설명서 페이지를 엽니다.

<b>포럼</b> - 브라우저에서 Adobe 커뮤니티 포럼을 엽니다.

<b>디스코드 서버</b> - 브라우저에서 에코시스템과 플러그인 디스코드 서버를 엽니다.

<b>타일링</b> - 재질의 X, Y 및 Z 타일링을 조정합니다. 잠금 기능을 사용하여 값의 연결을 해제하고 개별적으로 조정할 수 있습니다.

<b>텍스처</b> - 생성된 해상도의 기본 해상도입니다. 잠금을 해제하여 해상도를 독립적으로 설정하는 데 사용할 수 있습니다.

<b>적용 유형 </b>- 적용 단추의 동작을 설정합니다. <b>삽입 </b>은(는) 현재 재질을 선택한 Substance 재질로 재정의하며, <b>추가</b>는 재질을 새 재질 슬롯의 개체에 추가합니다.

<b>이미지 형식 내보내기</b> - Blender에서 생성된 이미지를 Substance 자료의 이미지 입력으로 사용할 때 이 형식은 해당 이미지를 임시 폴더에 저장하는 데 사용됩니다.

<b>기본적으로 입력 그룹이 축소됨</b> - Substance 자료의 입력 그룹이 기본적으로 확장되거나 축소되는 상태를 전환합니다.

<b>기본적으로 텍스처 업데이트만</b> - 날씨 업데이트 Substance 매개 변수를 전환하면 블렌더 음영 네트워크의 출력 텍스처에 영향을 줍니다. 이 옵션을 비활성화하면 매개 변수를 조정한 후 노드 연결이 재설정됩니다. 재료에 노드를 추가할 때는 활성화가 권장됩니다. 그렇지 않으면 매개변수를 조정한 후 연결이 끊어집니다.

<b>Substance 원격 엔진 </b>- Substance 원격 엔진에서 사용하는 하드웨어를 설정합니다.

<b>재질 자동 적용</b> - Substance 재질이 만들어지면 새 재질 슬롯에서 선택한 개체에 재질을 자동으로 연결합니다.

<b>선택한 개체의 재질을 자동으로 강조 표시</b> - 해당 재질이 있는 개체를 선택한 경우 Substance 3D 패널에서 강조 표시된 재질을 변경합니다.

<b>텍스처 자동 업데이트</b> 주기 - 렌더링 주기 보기를 사용하는 동안 3D 뷰포트에서 텍스처를 강제로 업데이트합니다.

<b>사전 설정 삭제 제거 확인</b> - 재질 사전 설정을 삭제할 때 나타나는 확인 창을 제거합니다.

<b>가짜 사용자가 활성화된 재질 만들기</b> - &quot;가짜 사용자&quot;를 활성화하거나 비활성화하여 재질이 만들어지는 날씨를 설정합니다. 가짜 사용자로 표시된 블렌더 데이터는 데이터가 사용되지 않아도 닫은 후 제거되지 않습니다.

<b>Substance 원격 엔진 </b>을(를) 자동으로 시작- 믹서를 시작할 때 Substance 원격 엔진이 초기화되면 토글합니다. 비활성화된 경우 사용자가 로드 버튼을 누르거나 로드 단축키를 사용할 때만 원격 엔진이 시작됩니다.

>[!NOTE]
>
> 참고: Substance Connector를 사용하는 경우, 송신 응용 프로그램이 Blender를 끝점으로 감지하기 위해 SRE가 활성화되어 있어야 합니다.

<b>SBSAR 라이브러리 경로</b> - [불러오기] 단추를 사용하여 Substance 파일을 검색할 때 기본적으로 열리는 폴더입니다.

<b>임시 폴더 </b>- 이 폴더는 파일을 처음 저장하기 전에 텍스처가 저장되는 기본 위치가 됩니다.

<b>저장할 때 .sbsar 파일 복사</b> - 활성화된 경우 파일을 저장할 때 .sbsar 파일이 지정된 상대 경로에 복사됩니다. 이를 통해 장치 간에 프로젝트를 쉽게 공유할 수 있습니다.

<b>저장할 때 텍스처를 복사</b> - 파일을 처음 저장하면 임시 폴더의 텍스처가 이 위치에 복사됩니다. $matname 변수는 각 재질에 대한 하위 폴더를 만드는 데 사용됩니다.

<b>셰이더 사전 설정</b> - substance 파일에서 Blender 재질을 만들 때 사용되는 기본 셰이더 사전 설정을 설정합니다. UV 기반 매핑 또는 상자, 구 및 원통 투영 기반 매핑의 투영을 표준으로 설정할 수 있습니다.

<b>변위 Midlevel</b> - 기본값은 변위 노드의 변위 기준입니다. 기본값보다 높은 값은 서피스를 바깥쪽으로 밀어내고 기본값보다 낮은 값은 서피스를 안쪽으로 당깁니다.

<b>변위 크기 조절</b>- 변위 노드의 기본 크기 조절 값입니다.

<b>발광 강도</b> - 기본 BSDF 노드의 발광 강도에 대한 기본값입니다.

<b>투영 혼합</b> - 투영 방법 셰이더의 각도 간 혼합 양을 설정합니다.

<b>AO 믹스</b> - 앰비언트 오클루전을 출력으로 사용할 수 있는 경우 이 값은 기본 색상과 앰비언트 오클루전 텍스처를 결합하는 데 사용되는 MixRGB 노드의 기본 요소 값을 결정합니다.

<b>출력</b> - 개별 재질 출력을 활성화하거나 비활성화할 수 있습니다. 개별 출력의 기본 색상 공간, 파일 형식 및 색상 깊이를 조정할 수도 있습니다.

<b>바로 가기 </b>- 유동 메뉴를 표시하고, Substance 자료를 로드하고, 현재 자료를 적용하는 데 사용되는 단축키 키를 사용자 지정합니다. 단축키 업데이트를 적용하려면 다시 시작해야 합니다.
