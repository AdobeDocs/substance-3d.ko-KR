# 추가 기능 제거

추가 기능을 제거하려면 편집 > 환경 설정 > 추가 기능으로 이동하고 추가 기능에 대한 섹션을 확장합니다.

1. 먼저 **제거 도구** 단추를 사용하여 통합 도구를 제거하십시오.
1. 그런 다음 **제거** 단추로 추가 기능 파일을 제거합니다

>[!NOTE]
>
> Substance 통합 도구를 수동으로 제거해야 하는 경우 다음 디렉터리에서 Substance3DInteintegrationTools 폴더를 삭제하십시오
> 
> * **Windows**: C:\Users\(사용자 이름)\AppData\Roaming\Adobe
> * **Mac**: /Users/(사용자 이름)/Library/Application Support/Adobe/Substance3DIntegrationTools
> * **Linux**: /home/(사용자 이름)/Adobe/Substance3DIntegrationTools
