# 플러그인 다운로드 및 설치

## 다운로드

추가 기능은 [Blender의 Substance 3D](https://substance3d.adobe.com/plugins/substance-in-blender/)에서 다운로드할 수 있습니다. <b>Blender용 Substance 3D 추가 기능 Adobe</b>를 클릭하여 Adobe 계정으로 로그인하고 다운로드 페이지에 액세스합니다. 페이지 하단으로 이동하여 Substance 3D 추가 기능 및 Substance 3D 통합 도구에 대한 .zip 파일을 다운로드합니다.

다운로드하고 설치할 두 개의 .zip 파일이 별도로 있습니다.

* Blender용 Substance 3D 추가 기능 (모든 플랫폼용 단일 다운로드)
* Substance 3D 통합 도구 (Windows, Mac 또는 Linux 버전 다운로드)

>[!WARNING]
>
> <b>Mac 사용자의 경우:</b> *사용자가 Safari에서 추가 기능을 다운로드하는 경우 &quot;다운로드한 후 안전 파일 열기&quot;를 비활성화해야 합니다.*
> 
> Safari 웹 브라우저는 기본적으로 다운로드한 .zip 파일의 압축을 푸는 것으로 설정되며, 이를 설치하려면 압축을 유지해야 합니다. 파일의 압축을 풀지 않도록 하려면 다운로드 후 &quot;안전한&quot; 파일을 열지 않도록 Safari 환경 설정을 업데이트하십시오.
> 
> 1. Safari 열기
> 1. 환경 설정 클릭
> 1. 일반 탭에서 다운로드 후 &quot;안전&quot; 파일 열기 옵션을 선택 해제합니다

## 설치 단계

### 최초 설치

1. Adobe 프리릴리스 페이지에서 추가 기능 .zip 파일을 다운로드합니다.
1. 블렌더 열기(v. 3.0 이상).
1. 상단 탐색 막대에서 편집, 환경 설정 순으로 선택합니다. 그런 다음 추가 기능 탭을 선택합니다.
1. **설치** 단추를 클릭합니다.
1. 파일 탐색기에서 .zip 파일이 다운로드된 폴더를 찾습니다
1. Substance3DInBlender.zip 파일을 선택하고 **추가 기능 설치** 단추를 클릭합니다.
1. 추가 기능 섹션에서 확인란을 클릭하여 추가 기능을 활성화하고 섹션 확장 아래의 드롭다운 화살표를 클릭합니다.
1. 통합 도구를 설치하라는 메시지가 표시됩니다. **디스크에서 설치**&#x200B;를 클릭하여 Substance3DIntegrationTools.zip을 선택하고 **도구 설치** 단추를 클릭합니다.\
   이전에 다운로드되지 않은 경우 **다운로드**&#x200B;를 클릭하여 브라우저에서 Adobe 프리릴리스 페이지를 열고 도구를 다운로드한 다음 **디스크에서 설치**&#x200B;를 사용하여 설치합니다.
1. 이제 추가 기능을 사용할 준비가 되었습니다!

### 추가 기능 및 도구 업데이트

1. Adobe 프리릴리스 페이지에서 최신 릴리스를 다운로드합니다.
1. **제거 도구** 단추를 사용하여 Substance 3D 통합 도구를 제거합니다.
1. **제거** 단추를 사용하여 추가 기능을 제거합니다.
1. 블렌더를 닫고 다시 시작합니다.
1. 상단 탐색 막대에서 편집, 환경 설정 순으로 선택합니다. 그런 다음 추가 기능 탭을 선택합니다.
1. **설치** 단추를 클릭합니다.
1. 파일 탐색기에서 .zip 파일이 다운로드된 폴더를 찾습니다
1. Substance3DInBlender.zip 파일을 선택하고 **설치** 추가 기능 버튼을 클릭합니다.
1. 추가 기능 섹션에서 확인란을 클릭하여 추가 기능을 활성화하고 섹션 확장 아래의 드롭다운 화살표를 클릭합니다.
1. 통합 도구를 설치하라는 메시지가 표시됩니다. **디스크에서 설치**&#x200B;를 클릭하여 Substance3DIntegrationTools.zip을 선택하고 **도구 설치** 단추를 클릭합니다.\
   이전에 다운로드되지 않은 경우 **다운로드**&#x200B;를 클릭하여 브라우저에서 Adobe 프리릴리스 페이지를 열고 도구를 다운로드한 다음 **디스크에서 설치**&#x200B;를 사용하여 설치합니다.
1. 이제 추가 기능을 사용할 준비가 되었습니다!

### 개별 구성 요소 업데이트

추가 기능만 업데이트하는 경우:

1. 추가 기능 환경 설정에서 **제거** 단추를 사용하여 추가 기능을 제거합니다.
1. 블렌더 다시 시작
1. 추가 기능 기본 설정으로 다시 이동하고 **설치** 단추를 사용하여 새 버전의 추가 기능을 로드합니다. 이전에 로드한 통합 도구는 그대로 유지됩니다.

통합 도구만 업데이트하는 경우:

1. 추가 기능 환경 설정에서 **도구 업데이트** 단추를 사용하여 최신 버전의 통합 도구를 로드합니다. 이전에 사용한 추가 기능은 그대로 유지됩니다.
1. 변경 사항을 적용하려면 Blender를 다시 시작하십시오.

또는

1. 추가 기능 환경 설정에서 **제거 도구** 단추를 사용하여 통합 도구를 제거합니다.
1. 블렌더 다시 시작
1. **디스크에서 설치** 단추를 사용하여 최신 버전의 통합 도구를 찾아서 로드합니다. 이전에 사용한 추가 기능은 그대로 유지됩니다.
