# 추가 기능 3.0.0+

**추가 기능 3.1.0**.*출시 날짜: 2026년 10월 20일*

**블렌더 추가 기능:**

* &lbrack;버그&rbrack; 고정 라이브러리 경로가 작동하지 않음
* &lbrack;Bug&rbrack; 다중 스레딩의 컨텍스트 문제가 해결되어 SBSAR 로드/업데이트에 실패함
* &lbrack;Bug&rbrack; 고정 텍스처 내보내기 형식이 무시됩니다.
* &lbrack;성능&rbrack; 다중 성능 개선

**Substance 통합 도구(Substance 원격 엔진):**

* &lbrack;기능&rbrack;이(가) Substance 엔진 9.6.1로 업데이트됨
* &lbrack;성능&rbrack; 종속성 업데이트 및 다중 성능 개선

**추가 기능 3.0.1**.*출시 날짜: 2026년 2월*

**블렌더 추가 기능:**

* &lbrack;Fixed&rbrack; 매개 변수 최소/최대 값이 작동하지 않음
* &lbrack;Fixed&rbrack; 물리적 크기가 사용자 정의 장면 배율로 작동하지 않음
* &lbrack;Fixed&rbrack; 물리적 크기가 비메트릭 시스템 장치에서 작동하지 않음
* &lbrack;Fixed&rbrack; Clearcoat maps not working with blender 4+
* &lbrack;Fixed&rbrack; 셰이더에서 Clearcoat 색상 맵이 누락되었습니다.
* &lbrack;Fixed&rbrack; AddOn 정의에서 잘못된 레이블
* &lbrack;Fixed&rbrack; Substance이 SRE를 무작위로 충돌( color float4 값 사용)
* &lbrack;Fixed&rbrack; 이미지 입력이 매개 변수 목록에 표시되지 않음
* 혼합기를 닫았다가 다시 연 후 &lbrack;Fixed&lbrack; 이미지 입력이 작동하지 않음

**Substance 통합 도구(Substance 원격 엔진):**

* 버전 3.0.1로 업그레이드
* 새 Linux 컴파일을 위해 C++11 ABI를 제거함
