# 추가 기능 0.9.3

**추가 기능 버전 0.9.3에 대한 릴리스 정보+**

* 추가 기능 환경 설정에서 OCIO 2.0 색상 공간 레이블을 추가합니다.
* 매개 변수/출력 팩토리에 설명을 도구 설명으로 추가합니다.
* 보고 기능 추가(전체)(침습적인 팝업을 제거하고 기본 블렌더 메시지로 대체).
* 추가 기능 환경 설정에서 설치하고 업데이트할 때 SRE 버전 레이블을 업데이트합니다.
* 출력 크기 및 임의화는 Substance에서 항상 사용할 수 있는 것이 아닙니다.

**환경 설정 섹션: 추가/업데이트:**

* 기본 셰이더 드롭다운에서 사용 가능한 사전 설정으로 사이클/이벤트 물리적 크기
* 물리적 크기 기본 투영 블렌드에 대한 컨트롤.
* 지원 링크를 변경하여 디스코드 서버를 가리켰습니다.
* 추가 기능 환경 설정에서 현재 SRE 버전이 올바르게 표시되는 문제를 해결합니다.
* 업데이트가 필요한 경우 모든 호환 가능한 버전의 추가 기능을 표시합니다.
* SRE가 없는 경우 첫 번째 버전 대신 지원되는 버전의 배열을 표시합니다.

**Substance 3D 패널 섹션: 추가/업데이트:**

* 그래프 매개변수(Graph Parameters) 아래에 재료의 물리적 크기(미터)가 표시됩니다.
* Cycles/Evee 물리적 크기는 셰이더 드롭다운에서 사용할 수 있습니다.
* 모든 매개 변수가 보이지 않으면 매개 변수 그룹을 숨깁니다.
