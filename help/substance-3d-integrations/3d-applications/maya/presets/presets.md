# 사전 설정

사전 설정 섹션에서 Substance sbsar 파일에 있는 포함된 사전 설정을 완전히 관리하거나 새 사전 설정을 만들 수 있습니다.

![](../../../assets/presets-15.png)

사전 설정을 만들려면 [Substance 매개 변수]를 변경한 다음 [만들기] 단추를 클릭합니다.

![](../../../assets/preset-save.gif)

사전 설정을 적용하려면 메뉴에서 사전 설정을 선택하고 적용을 클릭합니다. 사전 설정을 덮어써야 하는 경우 메뉴에서 사전 설정을 선택하고 [덮어쓰기] 버튼을 클릭합니다. 그러면 사전 설정이 새 설정으로 업데이트됩니다. Substance 사전 설정 파일(.sbsprs)을 가져오고 내보낼 수도 있습니다.
