# 출력 작업

출력 섹션에서 수동으로 출력을 활성화/비활성화할 수 있습니다.

![](../../../assets/outputs-1.png){width="800px"}

닫힌 원은 출력이 생성되었음을 나타냅니다. 위의 이미지에서 기본 색상이 생성되었음을 확인할 수 있습니다. 디스크로 출력 캐시 가 활성화되었기 때문에 Substance 출력 과 Maya 파일 노드가 만들어집니다. 파일 노드는 디스크의 캐시된 텍스처를 읽고 Substance 엔진이 텍스처를 처리할 때마다 자동으로 업데이트됩니다. 닫힌 원을 다시 클릭하여 출력을 비활성화하고 노드를 제거합니다.

![](../../../assets/enabled-3.png)

안경 아이콘을 클릭하여 Substance 출력 또는 파일 노드를 선택합니다. 파일 노드를 만든 경우에는 안경 아이콘을 클릭할 때 해당 파일 노드가 선택됩니다. 파일 노드가 없으면 Substance 출력이 선택됩니다. 이렇게 하면 출력 또는 파일 노드로 빠르게 이동할 수 있습니다. *\*팁: F 키를 누르면 프레임 편집기에서 선택한 노드가 표시됩니다. 출력이 많고 특정 파일 노드를 찾아야 할 때 유용합니다.*
