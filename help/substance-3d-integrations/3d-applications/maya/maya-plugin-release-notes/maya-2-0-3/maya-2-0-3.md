# Maya 2.0.3

이제 [웹 사이트](https://www.substance3d.com/ecosystem-plug-ins/substance-in-maya/)에서 2.0.3 버전의 플러그인이 릴리스되었습니다.

변경 사항:\
\* 이제 VRay 작업 과정에서 Vray 재질이 거칠기를 사용하도록 설정됩니다.\
\* 새 substance3d 사이트에 대한 일부 링크를 업데이트했습니다.\
\* 정보 메뉴에 Substance 엔진 버전을 추가했습니다.\
\* Substance 엔진 버전을 쿼리하는 스크립팅 명령을 추가했습니다.\
\* $pixelsize 입력 충돌 없음\
\* Designer에 설정된 값 입력은 이제 이미지 입력과 같이 노드에 표시됩니다.\
\* 이제 Redshift 작업 과정 스크립트는 brdf를 ggx로 설정하고 범프 노드를 탄젠트 공간 표준을 사용하도록 설정합니다.\
\* 예상 용도와 더 잘 맞는 새로운 Renderman 워크플로우 스크립트\
\* 이제 substanceSetWorkflow 명령이 문자열 인수를 올바르게 사용합니다.\
\* Maya 2020에 대한 지원이 추가되었습니다.

Maya 2018, Maya 2019 및 Maya 2020의 경우 Windows, MacOS 및 Linux에서 2.0.3이 현재 출시되었습니다. 또한 Windows 및 MacOS의 Maya LT 2018, Maya LT 2019 및 Maya LT 2020용으로 출시되었습니다.
