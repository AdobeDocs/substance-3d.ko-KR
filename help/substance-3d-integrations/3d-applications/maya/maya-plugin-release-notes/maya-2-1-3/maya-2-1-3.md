# Maya 2.1.3

2020년 6월 17일에 릴리스됨

오늘 우리는 플러그인의 2.1.3 버전을 출시했습니다.

2.1.3 릴리스:

* 이제 Windows에서 설치 관리자가 SHA-256으로 서명되었습니다.
* 이제 설치 관리자 내의 모든 바이너리가 Windows에서 서명됩니다.
* 이제 Windows에서 substance\_link.dll 및 substance\_portal\_cli.dll의 버전/설명 정보가 제공됩니다.
* Maya 2020의 표준 표면에 대한 워크플로우 옵션이 추가되었습니다.

이 버전은 Windows, Linux 및 Macos의 Maya 2017, 2018, 2019 및 2020용으로 출시되었습니다. 또한 Windows 및 MacOS의 Maya LT 2018, 2019 및 2020용으로 출시되었습니다.
