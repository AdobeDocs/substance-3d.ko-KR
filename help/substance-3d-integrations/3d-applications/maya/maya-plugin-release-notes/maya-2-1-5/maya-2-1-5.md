# Maya 2.1.5

2020년 8월 5일 릴리스됨

변경 목록:

* 이제 sbsar 파일이 표시되어야 하며 파일 경로 편집기에서 설정할 수 있습니다.
* 파일 경로는 프로젝트를 공유할 때 Maya의 상대 경로에 의해 설정해야 합니다
* 이제 Substance 시작 관리자에서 보내기 가 sbsar 파일을 프로젝트 디렉터리에 복사합니다.

이 버전은 Linux, MacOS 및 Windows의 Maya 2017, 2018, 2019 및 2020과 MacOS 및 Windows의 Maya LT 2018, 2019 및 2020용으로 출시되었습니다
