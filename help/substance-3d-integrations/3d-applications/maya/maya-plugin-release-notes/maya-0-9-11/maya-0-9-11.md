# Maya 0.9.11

**Maya 2.0 변경 내용:**\
**안정성**:

* 이제 그래프의 동적 특성이 특성 편집기 코드가 아니라 기본적으로 만들어집니다.
* Substance 노드는 UI 입력 없이 초기화될 때 일괄 생성할 수 있습니다
* 특성 편집기 및 속성 편집기가 훨씬 더 안정적입니다.
* GPU 엔진에서 8k 출력을 사용할 수 있을 만큼 메모리 성능이 크게 개선되었습니다.
* 이제 설정/환경 설정이 Maya 외부에서 쉽게 편집할 수 있는 별도의 구성 파일로 저장됩니다

**스크립팅**:

* 입력, 그래프 및 출력 정보 수집에서 sbsar 패키지 로드, 그래프 변경 및 사전 설정 관리자에서 사전 설정 작업 수행까지 모든 작업을 포함하는 강력한 스크립팅 API
* 공용 스크립팅 API와 동일한 기능을 사용하도록 디자인된 UI 코드

**Substance 기능**:\
**사전 설정 지원:**

* 디자이너에 설정된 포함된 사전 설정이 사전 설정 관리자에 로드됨
* 여러 사전 설정을 포함한 sbsprs 파일 가져오기 및 내보내기
* 사전 설정 관리자
* 엔진 V7 지원
* Designer 2019.1에서 릴리스되는 새 Substance 엔진과 이미 작동합니다.
* 숫자 출력은 페이지의 maya 출력 특성으로 렌더링됩니다
* Graph/substance 노드(하이퍼셰이드의 다른 노드에 연결할 수 있음)

**워크플로 시스템:**

* Arnold, Renderman, VRay, Corona 등을 위한 새로운 워크플로우
* Python의 사용자 정의 워크플로우 확장
* 하이퍼셰이드에서 작업 과정 스크립트를 되돌리고 사용자 정의 작업 과정을 한 번 설정하고 저장합니다.
* Substance Painter의 이미지 맵에 워크플로우 사용

**UI 및 UX 개선 사항:**

* 파일 -> import .sbsar가 substance 노드를 만듦
* 파일 브라우저에서 hypershade로 sbsar 파일을 드래그하여 놓아 substance 2 노드 만들기
* 이제 속성이 Designer에 설정된 범주에 따라 배치됩니다.

**기타 개선 사항:**

* 이제 이미지 입력이 프로시저 노드에서 작동합니다.
* 이제 프로시저 이미지 입력을 다운샘플링 또는 업샘플링할 수 있도록 프로시저 노드에 대한 샘플링 속도를 설정할 수 있습니다.
* 이제 출력 노드는 Substance Designer으로 인코딩된 출력 정보를 표시합니다.
* 이제 Substance/그래프 노드에서 그래프 정보(작성자 등)를 표시할 수 있습니다.
* 연결 재정의 및 특성 재정의와 같은 레이어 재정의 지원
* 디스크로 캐시 - 16비트, 16비트 부동 또는 32비트 부동 출력이 있는 출력인 모든 HDR 출력에 대해 exr 파일 유형을 선택합니다.
* 이전 플러그인에서 반사
* 새 플러그인으로 장면을 로드하면 이전 그래프 및 출력 노드가 substance 2 노드로 변환됩니다
