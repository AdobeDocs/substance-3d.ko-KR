# Maya 2.1.2

2020년 6월 2일 릴리스

오늘 우리는 플러그인의 2.1.2 버전을 출시했습니다.

변경 사항에는 다음이 포함됩니다.

* Stingray 셰이더 네트워크를 만들 때 Maya LT의 오류가 수정되었습니다.

이 기능은 Maya 2020.2에서도 릴리스되었으며 이를 위해 Maya 설치 관리자에 포함되어 있습니다.

동일한 플랫폼인 Maya 2017 - 2020 및 Maya LT 2018 - 2020용으로 출시되었습니다
