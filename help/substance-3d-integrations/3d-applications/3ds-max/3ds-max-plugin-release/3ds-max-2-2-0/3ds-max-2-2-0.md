# 3ds Max 2.2.0

릴리스됨: 2019/06/4

* 3ds Max 2020에 대한 지원 추가
* Designer 2019.1에서 가치 프로세서 지원을 추가하여 Substance 엔진 V7으로 업데이트됨
* 이제 플러그인이 자신과 관련된 Substance 엔진을 로드합니다.
* MSI 형식으로 변경하고 Microsoft 도구를 통한 적절한 자동 설치/제거
* 이제 설치 관리자 및 파일이 제대로 서명됨
* 설치 관리자가 더 이상 원래 플러그인에서 파일을 수정하지 않습니다.
* 3ds Max 2019(및 2020)에서 메뉴가 로드되지 않는 문제 수정
* ART 렌더러에 대한 기본 지원이 추가되었습니다.
* 광택 출력이 없는 경우 Corona 작업 과정 스크립트의 문제 수정
* 워크플로우 스크립트는 이제 일반 .ms 파일로 배포되며 검사할 수 있습니다.
* 더 작은 미용 변화 및 안정성 개선
