# 3ds Max 2.3.3

2020년 6월 3일 릴리스

오늘 2.3.2 상단에 버그 픽스 릴리스인 2.3.3 버전의 플러그인을 릴리스했습니다.

2.3.3 릴리스:

* 플러그인 파일이 SubstanceMax.dlt에서 substancemax.dlt로 이름이 변경되었습니다.
* substance\_link.dll에 버전 및 설명 정보 추가됨
* Redshift 검사 버전에서 해결된 문제, 이제 Redshift 3에서 작동해야 함
* Substance 노드에 sbsar을 로드한 후 실행 취소/다시 실행 시 충돌하는 문제를 수정했습니다.
* 설정 대화 상자를 사용한 회귀 수정 작동하지 않음
* 라틴 문자가 아닌 문자가 포함된 sbsar 파일을 로드할 때 발생하는 충돌 문제를 수정했음

당사의 릴리스 파이프라인 또한 완전히 다시 실행되었기 때문에 과거에 수행했던 크고 매우 멀리 있는 릴리스에 비해 훨씬 더 자주 릴리스가 출시될 것으로 기대할 수 있을 것입니다.

이 버전은 3ds Max 2018, 2019, 2020 및 2021용으로 출시되었습니다.
