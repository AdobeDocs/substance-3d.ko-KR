# 3ds Max 2.4.0

2020년 8월 10일 릴리스됨

추가됨:

* 새 Substance 재료 샘플

수정:

* 매개 변수 블록 충돌

알려진 문제:

* 키프레임이 있는 이전 장면을 Substance 개체에 로드하고 장면을 저장하고 다시 열지 않고 곡선 편집기를 열면 3dsMax가 충돌합니다. 해결 방법: 장면을 새로운 버전의 파일로 저장한 다음 다시 엽니다

이 버전은 3ds Max 2019, 2020 및 2021용으로 출시되었습니다.
