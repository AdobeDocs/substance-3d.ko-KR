# 일괄 가져오기

일괄 가져오기를 사용하여 여러 .sbsar Substance 파일을 일괄 가져올 수 있습니다.

1. 3ds Max UI 상단에 있는 Substance 설정으로 이동하여 Substance 일괄 가져오기 를 선택합니다.
1. 가져올 .sbsar 파일을 선택합니다.
