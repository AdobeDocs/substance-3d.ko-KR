# 사전 설정 사용

Substance 파일에는 포함된 사전 설정 파일이 포함될 수 있습니다. Substance에 포함된 사전 설정 파일이 있는 경우 [Substance 사전 설정] 창에 표시됩니다. [Substance 매개 변수]에 대해 선택한 설정에 따라 사용자 고유의 사전 설정을 만들 수도 있습니다.

![](../../../assets/max9.png)

1. 사전 설정 만들기 는 3ds Max Substance에 대해 설정한 매개 변수 설정을 기반으로 새 사전 설정을 만듭니다.
1. [사전 설정 가져오기]를 선택하면 사전 설정 파일(.sbsprs)을 가져옵니다.
1. [사전 설정 저장]을 선택하면 현재 선택한 사전 설정의 매개 변수 값이 저장됩니다.
1. 선택한 사전 설정을 내보내면 사전 설정이 사전 설정 파일(.sbsprs)로 내보내집니다.
1. 모든 사전 설정 제거 를 선택하면 사전 설정 목록의 사전 설정이 제거됩니다.
1. 선택한 사전 설정 제거 는 선택한 사전 설정만 제거합니다.
