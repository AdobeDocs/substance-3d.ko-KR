# Unity에서 Substance 3D 플러그인 다운로드

## 에셋 스토어

Unity용 Substance 3D Adobe은 [Unity Asset Store](https://assetstore.unity.com/packages/tools/utilities/substance-3d-for-unity-beta-213208)에서 사용할 수 있습니다. 플러그인이 Assets 폴더의 프로젝트에 추가됩니다.

## 패키지 관리자

Asset Store를 통해 플러그인을 추가하고 다운로드한 후 **내 에셋**&#x200B;에서 패키지 관리자(Unity 2020.3.27x 이상)를 사용하여 플러그인에 액세스할 수 있습니다.

![](https://helpx-prod.scene7.com/is/image/HelpxProd/screen-shot-2022-03-29-at-10-45-20-am?$png$&jpegSize=300&wid=1920)

### 패키지 관리자 캐시

Asset Store 캐시는 Package Manager/My Assets에서 사용할 수 있는 버전에 영향을 줄 수 있습니다. 최신 버전을 받지 못하는 경우 에셋 스토어 캐시를 삭제해야 할 수 있습니다.\
