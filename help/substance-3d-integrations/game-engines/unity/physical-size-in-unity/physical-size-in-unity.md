# 유니티의 물리적 크기

Unity용 [Substance 3D](https://www.adobe.com/products/substance3d/3d-augmented-reality.html) 플러그인의 물리적 크기 기능을 사용하면 Substance 재질을 실제 크기에 따라 적용하고 비율을 조정할 수 있습니다. 크기는 Designer과 같은 Substance 애플리케이션에서 설정되고 [플러그인] 패널의 물리적 크기 섹션에 표시됩니다.

이 기능은 현재 HDRP 워크플로우에서만 사용할 수 있습니다.

물리적 크기를 활성화하면 재질이 실제 크기(센티미터)를 기반으로 타일링됩니다. 재질 타일링은 오브젝트의 크기에 관계없이 동일하게 유지됩니다.

이 기능은 플러그인 패널 UI에서 &quot;물리적 크기 사용&quot;을 전환하여 활성화할 수 있습니다. 물리적 크기 값은 재질 타일링에 대한 예술적 제어를 위해 재정의될 수 있다.
