# 유니티 .

2020년 12월 9일 릴리스

수정:

* Unity 프로젝트에 Substance 자료가 포함된 경우 비트 코드 호환 iOS 앱을 생성할 수 없음

알려진 문제:

* Unity에서 Source의 에셋을 일관되게 다운로드할 수 없습니다. 해결 방법은 [Substance Source 웹 사이트](https://source.substance3d.com/)에서 다운로드하여 에셋을 수동으로 가져오는 것입니다.
* Unity 2020.2 이상은 현재 지원되지 않습니다
