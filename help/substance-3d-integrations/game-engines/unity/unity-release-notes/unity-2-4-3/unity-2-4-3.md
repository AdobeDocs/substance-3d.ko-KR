# 유니티 .

2019년 12월 릴리스

버그 수정:

* 고정: 노멀 맵 반전
* 수정됨: 검사기 내에서 수직 위치 문제 시작
* 수정: Inspector Graph의 &quot;생성된 텍스처&quot; 섹션에서 스크롤 막대 처리. 정리된 텍스트 디버그
* 수정됨: 플랫폼 확인 호버 텍스트의 &#39;PC, Max 및 Linux&#39; 맞춤법 오류
* 수정: 플랫폼 해상도 설정을 변경하고 재질 탐색 버튼을 클릭할 때 오류 발생
* 수정: HDRP 패킹이 AO를 올바르게 처리하지 않습니다. 녹색 채널 마스크 맵이 검정색임
* 수정: (회귀, Mac 전용) 유효한 텍스처 맵이 없는 숫자 출력/Substance 충돌 통일성.
* 수정: 충돌을 변경하고 Substance의 다른 인스턴스를 클릭할 때 발생합니다.
* 수정: 기본 Substance 개체를 클릭한 다음 Substance 그래프를 클릭하면 발생하는 GUI 오류(2019.2+에만 해당)
* 수정: Unity 2019.3 sbsar 파일 가져오기 오류
* 수정: 스크립트에 렌더링 호출이 없는 경우 Duplicate() 함수가 Substance을 완전히 렌더링하지 않음
