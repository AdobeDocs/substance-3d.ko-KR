# 유니티 .

2020년 7월 23일에 릴리스됨

추가됨:

* 렌더러가 사용 중인지 [유휴 상태](사용 중이 아님)를 나타내는 &quot;IsProcessing()&quot; 함수

수정:

* 2048 클램프 및 4096 대상 설정을 설정할 때 더 이상 오류가 표시되지 않음
* Standard에서 HDRP 및/또는 URP로 업그레이드할 때 재질 속성이 그대로 유지됩니다
* Substance 재질을 변경하는 스크립트는 모바일에 배포할 때 예상대로 작동합니다.
* 빨간색 Alpha이 더 이상 Alpha에 복사되지 않으며 기본값 설정 채널이 흰색으로 설정됩니다.
* Mac에서 대상 설정 변경 충돌
* Unity 재질을 만들 때 NullReferenceException 오류가 발생했습니다.
* 타일링 속성을 편집한 후 재생 모드를 종료할 때 오류 제거됨
* GPU 인스턴스 활성화 가능
* 기존 재생 모드에서 투명도를 사용하는 재질이 사라지거나 잘못 검정으로 변환되지 않습니다
* 플러그인을 업그레이드할 때 HDRP 프로젝트에서 Substance 재질이 제거되지 않음
