# Unity 릴리스 정보

현재 Unity 3.0.0 버전부터 Unity용 Substance 3D Adobe 플러그인을 지원합니다. Unity 이전 버전용 Substance 3D 플러그인의 이전 버전은 조만간 지원이 중단됩니다.

**2.2.0에서 2.6.0까지의 Unity 버전은 조만간 더 이상 사용되지 않습니다.**
