# 유니티 .

## 2.2.2 릴리스 정보

**출시일: 2019/2/11**

### 코어 플러그인:

* Unity의 Substance 플러그인을 설치할 때 Unity 기본 텍스처 GUI를 덮어쓰는 버그가 수정되었습니다.
  * EditorApplication.delayCall 설정 시 다른 플러그인에 문제가 발생하는 버그를 수정했습니다.
  * 프로젝트 이름에 라틴어가 아닌 문자를 사용할 때 발생했던 충돌을 수정했습니다.
