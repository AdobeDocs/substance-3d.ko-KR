# 유니티 .

2021년 6월 27일에 릴리스됨

업데이트/추가됨:

* Apple Silicon 지원
* 플러그인 사용 방법에 대한 새로운 YouTube 튜토리얼
* 새로운 스크립팅 설명서
* Substance 그래프 편집기 및 기본 Substance 파일 편집기에서 control-z 지원
* 많은 수의 sbsar 파일을 로드할 때 성능 향상
* 여러 그래프가 있는 Substance 재질 지원
* Substance 그래프 관리 UI를 변경했습니다.
* C#을 통해 사전 설정을 로드하는 노출된 API
* 업데이트된 온라인 설명서

수정:

* [임의화] 버튼을 여러 번 누르면 검사기에 표시되는 버그
* Substance 업데이트를 중단하는 Null 텍스처 입력
* &quot;모든 출력 생성&quot;, &quot;Mip 맵 생성&quot; 및 &quot;런타임 전용&quot; 토글이 작동하지 않음
* 네임스페이스 문제
* 그래프 에셋이 선택된 상태에서 재생 모드로 들어갈 때 Null 참조 오류 발생
* 런타임 전용 재질을 사용할 때 최신 2021.3 LTS 버전의 Unity에 대한 HDRP 및 URP의 문제
* 여러 입력이 있는 sbsar 파일의 성능 문제
* &quot;핸들이 이미 해제되었습니다&quot; 오류
* &quot;재생 모드 시작 시 파란색으로 이동&quot; 문제
* sbsar 파일의 Height 맵 문제
* 읽을 수 없는 텍스처를 읽는 이미지 입력 관련 문제

알려진 문제:

* 출력 텍스처의 R 및 B 채널이 뒤집히는 Mac 문제를 해결합니다
* Mac의 주요 성능 개선 사항
