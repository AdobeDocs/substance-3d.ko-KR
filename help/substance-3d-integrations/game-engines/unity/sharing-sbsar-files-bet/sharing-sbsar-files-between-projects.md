# 프로젝트 간 sbsar 파일 공유

.sbsprs 파일을 사용할 때 매개 변수 조정을 동일하게 유지하면서 프로젝트와 컴퓨터 간에 .sbsar 파일을 공유할 수 있습니다.

원본 프로젝트의 재질이 공유될 설정으로 수정된 후 [검사기] 패널에서 사전 설정 설정으로 이동합니다. 사전 설정 설정에서 새 사전 설정을 만들고 이름을 지정합니다. 이 재질의 사전 설정 목록에 이름이 지정된 이 새로운 사전 설정이 나타납니다. 그런 다음 사전 설정을 내보내 로컬에 저장합니다.

다른 프로젝트나 컴퓨터에서 .sbsar를 사용하는 경우 내보낸 사전 설정 파일도 포함합니다. sbsar을 [유니티] 프로젝트로 가져온 후 사전 설정 설정으로 이동하고 가져오기 옵션을 선택합니다. 이전 단계에서 사전 설정 파일을 선택하고 가져옵니다. 이전 프로젝트의 설정이 포함된 사전 설정을 사전 설정 목록에 추가해야 합니다.

공유되는 모든 재질에 대해 반복합니다.
