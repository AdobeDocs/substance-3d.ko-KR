# 이미지 입력 사용

Substance의 입력 매개 변수에 이미지를 사용하려면 다음을 수행하십시오.

1. Substance 그래프의 관리자 창에서 프로젝트의 텍스처를 선택하여 이미지 입력에 할당할 수 있습니다.

   ![](../../../assets/imageinput-inspector.png)
1. Substance 자료에 텍스처 데이터를 읽는 데 필요하므로 텍스처를 선택하면 &quot;읽기/쓰기 가능&quot; 필드가 선택됩니다

   ![](../../../assets/imageinput-texture.png)
