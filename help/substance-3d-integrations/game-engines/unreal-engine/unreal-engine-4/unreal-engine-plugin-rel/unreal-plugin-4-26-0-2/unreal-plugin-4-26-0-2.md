# Unreal 플러그인 4.26.0.2

추가됨:

* Substance 엔진 v 8.0.3 지원
* Substance Source 작업이 이제 Substance 시작 관리자 내의 소스 탭에 액세스하여 에셋을 UE4([추가 세부 정보](../../../../../game-engines/unreal-engine/unreal-engine-4/source-in-ue4/source-in-ue4.md))로 직접 보낼 수 있습니다.
* 프로젝트 버전을 업그레이드할 때 한 번에 처리되는 Substance 자료의 수가 줄어듭니다.

수정:

* UE4 Substance 플러그인이 설치된 상태에서 편집기를 닫을 때 Mac에서 UE4가 충돌함
* Substance 그래프 인스턴스에서 텍스트 매개 변수를 변경하면 멈춤 및 최종 충돌이 발생합니다
