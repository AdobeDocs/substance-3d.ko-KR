# Substance 3D 플러그인 기본 템플릿

*참고: 이 기능은 현재 개발 중이며 곧 사용할 수 있습니다.*

버전 5.0.0에서는 Substance 엔진에서 지원하는 숫자 출력으로 개선된 재질 템플릿 워크플로 *을(를) 도입했습니다. 재질 템플릿을 사용하면 UE5에서 Substance 재질 셰이더를 구성하는 방법을 정확하게 정의할 수 있습니다.*
