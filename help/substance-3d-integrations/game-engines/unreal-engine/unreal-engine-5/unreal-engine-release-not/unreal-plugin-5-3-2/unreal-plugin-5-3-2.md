# Unreal 플러그인 5.3.2

2023년 12월 4일 릴리스

<b>고정</b>

* Unreal Engine 5.3용 Mac에서 작동하지 않는 Substance 플러그인과 관련된 호환성 문제를 해결했습니다.
* Unreal Engine용 Substance 플러그인에서 재질 충돌을 선택 취소해도 더 이상 채널이 발생하지 않는 문제를 해결했습니다.
* 플러그인의 &#39;stone-arc.sbars&#39; 재질이 전체 범위의 수정 가능한 재질 속성을 표시하지 않고 [입력] 섹션 아래에서 &#39;출력 크기&#39; 옵션만 표시하는 문제를 해결했습니다.
* Substance 플러그인에서 가져온 재질에 잘못된 빨간색 이동 표준 및 색상 베이스 맵이 표시되는 색상 이동 문제를 해결했습니다.
* .sbsar 파일에서 &#39;다시 가져오기&#39;를 사용하면 편집기가 충돌 되는 Substance 플러그인의 충돌 문제를 수정했습니다.
* Substance 플러그인에서 입력 유효성 검사를 개선하여 주요 질감 속성 필드의 범위가 벗어나고 잘못된 항목이 표시되지 않도록 했습니다.&quot;
* Substance 플러그인에서 두 번째 그래프 인스턴스를 만들면 이전에 로드한 사전 설정이 모두 제거되는 버그가 수정되었습니다.&quot;
* Substance 팩토리 인스턴스를 다시 가져오면 기존 사전 설정이 모두 제거되는 문제가 해결되었습니다.
