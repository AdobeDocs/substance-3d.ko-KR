# 오류 및 경고 메시지

아래는 Substance 소프트웨어로 구울 때 나타날 수 있는 모든 오류 메시지 목록입니다.

## 모든 제빵사

| *메시지* | *설명* |
| --- | --- |
| 베이커는 안 돼요 | 이 오류 메시지 다음에는 일반적으로 GPU 문제와 관련된 추가 오류 메시지가 표시됩니다. GPU가 너무 오래되어 소프트웨어의 [기술 요구 사항](https://www.allegorithmic.com/products/tech-specs)을 충족하지 못하는 경우 발생할 수 있습니다. |
| UV 세트 [X]이(가) 없습니다. | 베이커는 낮은 폴리 메쉬에는 없는 주어진 UV 세트를 가지고 작업하려고 했다. |
| URL에서 장면을 로드할 수 없습니다. | 이 메시지는 제빵사가 메쉬 파일, 일반적으로 높은 폴리 메쉬를 로드할 수 없었음을 의미합니다. 이 메시지의 출처는 다음과 같습니다.<ul data-preserve-html="true"><li data-preserve-html="true">참조된 메시 파일이 더 이상 존재하지 않습니다.</li><li data-preserve-html="true">메시 파일이 손상되었거나 손상되어 읽을 수 없습니다.</li><li data-preserve-html="true">메쉬는 현재 다른 응용 프로그램에서 편집 중이므로 읽을 수 없습니다.</li></ul> |

## UV에서 SVG 베이커로

| *메시지* | *설명* |
| --- | --- |
| 메시 [메시 이름]에 대한 UV를 찾을 수 없습니다. | 특정 메쉬와 관련된 UV가 발견되지 않았습니다. 여러 메시를 가져오지만 일부 메시에만 UV가 있는 경우 이러한 현상이 발생할 수 있습니다. |
| 장면에 자외선이 없어요. 베이크를 취소하는 중입니다. | 장면에 UV가 있는 메쉬가 없는 경우 베이크 프로세스가 취소됩니다. |

## 위치 베이커

| *메시지* | *설명* |
| --- | --- |
| 메시 [메시 이름]에 위치가 없습니다. | 낮은 폴리 메쉬는 정점 위치를 갖지 않습니다. |
| 메쉬 [메쉬 이름]에 uv 세트 [X]에 대한 UV가 없습니다. | 베이커는 낮은 폴리 메쉬에는 없는 주어진 UV 세트를 가지고 작업하려고 했다. |

## Any &quot;From Mesh&quot; Baker

| *메시지* | *설명* |
| --- | --- |
| 메시 [메시 이름]에서 정점 표준을 찾을 수 없습니다. | 주어진 메쉬에서 정점 법선이 발견되지 않았다. 정점의 수직은 메쉬에 없는 경우 다시 계산되므로 일반적으로 발생하지 않습니다. 잘못된 사용자 정의 탄젠트 공간 플러그인으로 인해 발생할 수 있습니다. |
| 메시 [메시 이름]에서 꼭지점 접선을 찾을 수 없습니다. | 위와 동일. |
| 메시 [메시 이름]에서 정점 이항식을 찾을 수 없습니다. | 위와 동일. |
| 메시 [메시 이름]에서 꼭지점 색상을 찾을 수 없습니다. | 주어진 메쉬에서 정점 색상을 찾을 수 없습니다. 이는 하이-폴리 메시 내의 적어도 하나의 서브-메시가 어떠한 정점 색상들도 정의되지 않은 경우에 발생할 수 있다. |
| 선택한 베이커를 사용할 수 있는 높은 수준의 데이터가 충분하지 않습니다. 굽기를 중단합니다. | 앞에 위의 메시지 중 하나 이상이 옵니다. 일반적으로 장면에서 약간의 데이터만 누락된 경우(예: 높은 폴리 장면의 한 메쉬에만 꼭지점 색상이 없음), 처리하고 누락된 데이터를 0으로 채우고 베이크를 유지합니다. 데이터가 너무 많으면 이 메시지가 출력되고 베이킹 프로세스가 중지됩니다. |

## 메시에서 전송된 텍스처

| *메시지* | *설명* |
| --- | --- |
| 세부 텍스처를 로드하지 못했습니다. | 베이커 설정에 정의된 텍스처를 로드할 수 없습니다. 파일이 디스크에 실제로 없거나 손상되어 읽을 수 없기 때문일 수 있습니다. |
