# 메시의 불투명 마스크

메시 베이커의 불투명도 마스크는 놓친 광선이 회색 음영의 이진 이미지로 변환되는 텍스처를 계산합니다. 이 텍스처는 일반적으로 불투명도 맵으로 사용됩니다.

텍스처 속성은 다음과 같이 정의됩니다.

* 검은색 값은 빈 영역을 나타냅니다.
* 흰색 값은 볼록 영역을 나타냅니다.

**사용 가능 대상:**

* Painter
* Designer
* 자동화 툴킷

## 매개 변수:

이 제빵사는 특정한 매개 변수를 가지고 있지 않다.
