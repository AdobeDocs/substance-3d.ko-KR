# 실제 공간 표준

월드 스페이스 수직 제빵사는 메시를 법선, 접선, 이항식으로 텍스처에 저장할 수 있습니다.

**사용 가능 대상:**

* Substance Designer
* Substance 자동화 툴킷

## 매개변수

| *매개 변수* | *설명* |
| --- | --- |
| **굽기 유형** | 베이커가 수행할 계산 유형을 정의합니다.가능한 값:<ul data-preserve-html="true"><li data-preserve-html="true"><strong>표준</strong>(기본값)</li><li data-preserve-html="true"><strong>접선</strong></li><li data-preserve-html="true"><strong>이진</strong></li></ul> |
| **표준 맵** | 세부 사항을 추가하기 위해 계산 중에 사용되는 입력 표준 텍스처의 경로입니다. |
| **일반 방향** | **베이킹 유형**&#x200B;이 **표준**(으)로 설정된 경우 입력 텍스처의 표준 형식을 정의합니다.가능한 값:<ul data-preserve-html="true"><li data-preserve-html="true"><strong>OpenGL</strong></li><li data-preserve-html="true"><strong>DirectX</strong>(기본값)</li></ul> |
