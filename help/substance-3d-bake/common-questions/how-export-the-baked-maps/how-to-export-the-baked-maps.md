# 베이킹된 맵을 내보내는 방법

>[!WARNING]
>
> **질문**
> 
> 메시에서 구운 텍스처를 다른 응용 프로그램에 사용하기 위해 내보내는 방법은 무엇입니까?

>[!NOTE]
>
> **해결 방법: Substance Designer**
> 
> 베이커스의 출력 파일은 메쉬가 연결된 Substance 그래프 옆에 있어야 합니다. 마우스 오른쪽 버튼을 클릭하고 &quot;탐색&quot;을 선택하여 애플리케이션의 탐색기 창에서 파일을 봅니다.

>[!NOTE]
>
> **해결 방법: Substance Painter**
> 
> 베이커의 출력 파일은 프로젝트 파일(\*.spp)에 저장됩니다. 내보내려면 다음 중 하나를 수행합니다.
> 
> * **파일 > 텍스처 내보내기** 대화 상자를 사용하고 내보내기 사전 설정 &quot;메시 맵&quot;을 선택합니다
> * [선반]에서 구운 텍스처를 마우스 오른쪽 버튼으로 클릭하고 &quot;내보내기&quot;를 선택합니다.

>[!NOTE]
>
> **솔루션 : Substance 자동화 툴킷**
> 
> 베이커의 출력 파일은 기본적으로 망 옆에 저장됩니다. 명령줄에서 특정 인수를 통해 출력 폴더를 변경할 수 있습니다.
