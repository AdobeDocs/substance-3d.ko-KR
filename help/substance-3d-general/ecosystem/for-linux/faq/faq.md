# 자주 묻는 질문

+++새로운 ADA 포털은 무엇이며, 이를 사용하여 무엇을 할 수 있습니까?


ADA 포털을 통해 중앙 위치에서 라이선스 및 인증을 관리할 수 있습니다. ADA 포털을 사용하여 다음을 수행할 수 있습니다.



* 현재 및 이전 라이선스 다운로드.

현재 및 이전 라이선스 다운로드.

* 디지털 인증에 액세스하고 다운로드하세요.

디지털 인증에 액세스하고 다운로드하세요.

* 계정과 연결된 연락처를 추가하거나 삭제합니다.

계정과 연결된 연락처를 추가하거나 삭제합니다.

+++

+++주문 확인 이메일을 받지 못한 경우 어떻게 해야 합니까?


먼저 스팸 또는 정크 메일 폴더를 확인하여 이메일이 해당 폴더로 배달되지 않았는지 확인하십시오. 여전히 이메일을 찾을 수 없는 경우 계정 관리자 또는 CSM에 문의하십시오.



+++

+++이전 버전의 소프트웨어를 설치하려면 어떻게 합니까?
이전 버전의 소프트웨어를 검색하고 다운로드하려면:

* ADA의 다운로드 섹션을 엽니다.

* &quot;기타 버전&quot;을 클릭합니다.

+++

+++연락처를 추가하거나 삭제하려면 어떻게 해야 합니까?


계정을 추가하려면 다음을 수행하십시오.

* 페이지 헤더에서 연락처를 엽니다.

* &quot;연락처 추가&quot;를 클릭합니다.

* 연락처 정보를 입력합니다.

* [저장]을 클릭합니다.





연락처를 삭제하려면 다음을 수행하십시오.

* 페이지 헤더에서 연락처를 엽니다.

* 계정 이름 옆에 있는 확인 표시 상자를 선택합니다.

* 페이지 오른쪽에 있는 &quot;연락처 제거&quot;를 클릭합니다.



+++

+++포털에 로그인하는 데 문제가 있습니다. 어떻게 해야 합니까?


잘못된 이메일 또는 암호와 관련된 오류 메시지가 표시되는 경우 계정과 연결된 올바른 자격 증명을 사용하고 있는지 확인하십시오.





다른 유형의 오류가 발생한 경우 [당사의 기업 지원 팀에 문의](https://helpx.adobe.com/kr/enterprise/using/support-for-enterprise.html)하십시오.



+++

+++이전 주문 구매 내역을 보려면 어떻게 해야 합니까?
구매 주문 내역은 LWS 포털을 통해서만 액세스할 수 있습니다. LWS 포털에 액세스하려면 다음을 수행합니다.

* [Adobe 라이선싱 웹 사이트](https://licensing.adobe.com/)로 이동합니다.

* LWS 계정에 로그인합니다.

* 보고서를 클릭합니다.

* 구매 내역 보기를 선택합니다.

* Adobe 주문 번호를 입력합니다.

* [검색]을 클릭합니다.

[LWS에 대한 자세한 내용은 여기에서 확인할 수 있습니다](https://helpx.adobe.com/kr/x-productkb/policy-pricing/volume-licensing-site.html).



+++

+++도움이 더 필요한 경우 누구에게 문의할 수 있습니까?
추가 지원이 필요한 경우 당사의 기업 지원 팀에 문의할 수 있습니다. 관리자가 [Adobe Admin Console에 로그인하고 지원 사례를 열어야 합니다](https://helpx.adobe.com/kr/enterprise/using/support-for-enterprise.html).

추가 지원이 필요한 경우 Adobe CSM에 문의할 수 있습니다.

+++

+++ADA의 라이선스 키 파일로 소프트웨어를 활성화할 수 없습니다.
[자세한 활성화 지침은 여기에서 확인할 수 있습니다](../../../ecosystem/for-linux/substance-for-linux.md). 그래도 문제가 해결되지 않으면 [기업 지원 팀에 문의](https://helpx.adobe.com/kr/enterprise/using/support-for-enterprise.html)하세요.

+++
